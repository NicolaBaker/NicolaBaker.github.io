# Portfolio personnel

Bienvenue sur mon portfolio !

Je suis étudiant en génie logiciel à l'Université d'Ottawa et passionné par le développement web, le design et les nouvelles technologies.

Ce site a été conçu pour présenter mon parcours, mes compétences et les différents projets que j'ai réalisés.

## Contenu du site

- **À propos** — Mon parcours personnel et professionnel.
- **Expériences** — Mes expériences de travail et mes stages.
- **Compétences** — Les technologies et les outils que j'utilise.
- **Projets** — Mes réalisations personnelles, universitaires et professionnelles.
- **Contact** — Mes coordonnées pour communiquer avec moi.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Objectif

Ce portfolio me permet de présenter mon travail, de partager mes connaissances et de montrer l'évolution de mes compétences dans le domaine du génie logiciel.
